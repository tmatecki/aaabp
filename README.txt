AutoAutoAuto by BP - interactive deck

Upload EVERYTHING in this folder to the root of your GitHub Pages branch
(or into /docs if that is what Pages is set to serve).

  index.html                the deck
  AutoAutoAuto-BP-PL.pdf    linked from the download button on the last slide
  AutoAutoAuto-BP-EN.pdf    same, English
  fonts.css + fonts/        the three typefaces, self-hosted (no Google Fonts request)
  img/                      screenshots, camera frame, console panels, BP Helios
  .nojekyll                 stops Jekyll processing - keep it, it is not optional

Keep the structure exactly as it is; all paths are relative.
GitHub Pages is case-sensitive - do not rename anything.
If you replace the PDFs, keep the filenames or the download button will 404.
